# 嵌入式 C 的十二个硬骨头 · 可视化讲义

一个零依赖、可离线打开的单页交互讲义。用内存格子、总线信号、栈帧、宏展开轨迹和单步时序，
把嵌入式 C 里最容易“看懂字面、想不通现场”的难点画出来。

## 打开方式

直接双击 `index.html`，或把它拖进浏览器。不需要安装、不需要联网，也没有构建步骤。

- `index.html` — 页面结构与全部讲解文案
- `styles.css` — 暖白阅读主题、桌面侧边目录、窄屏折叠导航、动画与响应式
- `app.js` — 12 个演示的状态机与交互逻辑

## 包含的 12 个实验

1. **内存地图** — 上电复位、`.data` 复制、`.bss` 清零、函数调用、`malloc`、
   栈溢出，观察栈与堆如何相向生长。
2. **volatile** — 对比“读取被提升到 R0”和“每次都读内存”，亲手触发中断看死循环。
3. **寄存器指针** — 把 `*(volatile uint32_t *)ADDR |= (1u << 5)` 拆成三步执行，
   对应位与 LED 同步点亮；并补充“数组与指针”实验，对比 `a / &a / a + 1 / &a + 1`
   的地址步长，以及数组传参后 `sizeof` 退化为指针大小。
4. **位操作** — 点击 8 个位格直接拨动寄存器，配合置位、清位、翻转和随机图案。
5. **结构体对齐** — 默认布局、`packed`、成员重排三种布局的 padding 与 `sizeof`。
6. **大小端** — 同一个数值在小端/大端下的四字节排列与 `p[0]`；交换按钮改变数值的字节，保持所选存储顺序；
   把首字节从 `0x7F` 切到 `0x80`，对照有符号左移的 UB 与先转 `uint32_t` 的结果。
7. **中断原子性** — 主循环与 ISR 交错的 9 步指令级动画，看清 `count++` 如何丢更新；
   可切换“关中断保护”对比结果，并支持暂停、单步和调速。
8. **const 指针** — 三种声明的“锁数据 / 锁指针 / 全锁”，点击尝试修改看编译结果。
9. **整数陷阱** — `uint8_t` 数到 255 回绕的死循环动画，以及整型提升、隐式转换、
   有符号溢出、无符号回绕四张卡片。
10. **启动流程与栈** — 复位向量到 `main` 的 6 步流程，拖动滑块让栈帧撞上 `.bss`。
11. **宏展开** — 选择“错误/正确”的 `SQ` 定义和参数，逐步看文本替换、优先级与
    重复求值；再用开关对比没有 `do { } while (0)` 时悬空 `else` 的后果。
    展开轨迹支持播放、单步、暂停与调速。
12. **预处理器武器库** — 条件编译开关、`#` 字符串化、`##` 拼接、两级 `XSTR`，
    以及用 X-Macro 一张表生成 `enum`、名字表和初始化表。

volatile、寄存器指针、中断与宏展开提供 **播放 / 单步 / 暂停 / 重置 / 速度**。
整数回绕实验可运行或重置，启动流程进入视口后自动展示。
寄存器位格支持鼠标与键盘切换，LED 和读数随之更新。

页面底部还有一张“嵌入式 C 生存清单”，把常用写法和三个常见误解集中在一起。

## 说明

- 地址、寄存器名、RAM 大小、宏展开结果与日期宏均为教学示例（STM32F1 风格），
  不是某颗芯片或某个编译器的完整手册。
- 所有演示都在浏览器本地计算，不发送任何数据。
- 支持键盘聚焦按钮；若系统开启“减少动态效果”，动画会自动降级。
- 教学默认使用 32 位指针与常见 C11/C17 工具链；栈越界可能破坏相邻数据，不保证立即触发 HardFault。
- 阅读布局：宽屏同时显示实验与解释；较窄屏幕按顺序排列；代码和数组内存图可在自身区域横向滚动。
